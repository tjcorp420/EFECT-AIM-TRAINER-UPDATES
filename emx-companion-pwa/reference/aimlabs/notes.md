Implementation takeaways for EMX:

- Keep the companion app focused on live utility first: leaderboards, updates, converter, player goals.
- Mirror the useful conversion model, not the visuals: origin game, target game, sensitivity, DPI, converted sens, and cm/360.
- Make releases visible in the app so the auto-updater feels connected to a public update feed.
- Add lightweight practice stack guidance, but keep it editable/local instead of pretending to be a full coaching system.
- Keep the EMX UI ownable: black glass panels, green/cyan/pink accents, and EMX naming instead of copying Aimlabs branding or assets.
